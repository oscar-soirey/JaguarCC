Jaguar
Langage compilé

Un langage compilé, avec son propre outillage.

Jaguar est un langage compilé, à la syntaxe proche du C : types explicites, classes, namespaces et collections simples — avec un runtime qui garde la gestion mémoire hors de portée du code. Un compilateur, un build system et un bindgen forment sa chaîne d'outils.

Ce que couvre le langage

Une syntaxe familière, un runtime plus sûr.

Jaguar reprend volontairement plusieurs idées du C tout en simplifiant certains aspects du quotidien.

Compilateur classique

jcc compile vos programmes en exécutables natifs, avec un mode --c89 pour la portabilité.

Types explicites

Types C classiques et alias courts (i32, f64, u8…), normalisés par le compilateur.

Classes & héritage

Champs, méthodes, constructeurs/destructeurs, méthodes virtuelles, override et contrôle d'accès ($ / %).

Surcharge & namespaces

Plusieurs fonctions de même nom, arguments nommés, et un name mangling qui évite les collisions entre namespaces.

Collections simples

list, map, pair, container et dynamic_list, avec une syntaxe volontairement simple.

Runtime maîtrisé

Pas de malloc/free ni de pointeurs bruts exposés : le runtime gère strings, classes et containers.

Sous le capot

Proche du C, avec ses propres règles.

Jaguar assume quelques choix qui le distinguent volontairement du C classique.

Contrôle d'accès

Privé par défaut, un symbole pour le reste

Un membre de classe sans marqueur est privé. $ le rend public, % le rend protégé — vérifié par le compilateur.

class Player { $int health = 100; %int stamina; int secret_value; int get_health() const { return health; } }
Ownership

container<T> possède sa donnée

Un container détruit automatiquement l'objet qu'il possède. Pratique pour une classe allouée avec new, sans gérer sa libération à la main.

container<Player> player = new Player(100); player.get().damage(25); // forme courte pour un type simple container<int> value => 42;
Boucles

while sans condition, for_loop inclusif

Le while Jaguar ne prend jamais de condition — on sort avec break. for_loop inclut sa borne finale.

while { if (health <= 0) { break; } health = health - 1; } int i = for_loop(0, 10) { sys:print(i); // 0..10, borne incluse }
Appels de fonctions

Arguments nommés et valeurs par défaut

Un paramètre peut avoir une valeur par défaut, et être passé par nom dans n'importe quel ordre — tant qu'aucun positionnel ne suit un nommé.

int move(int x, int y, int speed = 1) { return x + y + speed; } move(y = 20, x = 10); move(x = 10, y = 20, speed = 5);
Interop C

Namespaces manglés, sorties explicites vers le C

Une fonction dans un namespace est manglée pour éviter les collisions. @extern désactive ce mangling pour appeler du C natif.

namespace math { int add(int a, int b) { return a + b; } // devient math_add côté C } @extern int native_function(int value);

Chaîne d'outils

Trois outils, un seul langage.

jcc compile, jbs orchestre les builds, jbg importe des API C existantes.

Compilateur

jcc, le compilateur Jaguar

jcc est un compilateur classique : il prend un programme Jaguar et produit un exécutable. En détail, il passe par une étape de transpilation vers le C avant d'appeler un compilateur C — une implémentation interne plutôt qu'une contrainte du langage.

jcc main.ja -o game jcc main.ja --c89 -o game // sans -o : le C généré est écrit sur la sortie standard jcc main.ja > main.c
Build system

jbs, l'orchestrateur de build

jbs décrit un projet dans un fichier de configuration : options de compilation, macros globales, cibles à compiler et étapes de link.

version 1.0 out . include lib c89 keep_c define PI 3.14 compile Main { main.ja } link Main { add.a }
Bindgen

jbg, importer une API C

jbg génère des déclarations Jaguar (des @extern) à partir d'une API C existante, pour appeler une bibliothèque C sans écrire les signatures à la main.

// génère les bindings depuis un en-tête C jbg mylib.h -o mylib_bindings.ja // utilisables directement depuis Jaguar @extern int mylib_init();

Compiler et exécuter un programme

Avec Python et GCC installés.

  1. git clone https://github.com/oscar-soirey/JaguarCC.git
    Récupère le compilateur jcc.py et ses sources.
  2. python jcc.py main.ja -o game
    Génère game.c, puis appelle GCC pour produire l'exécutable game.
  3. python jcc.py main.ja > main.c
    Sans -o, seul le C généré est écrit sur la sortie standard.
  4. python jcc.py main.ja --c89 -o game
    Génère un C compatible C89 — la sémantique Jaguar reste identique.
