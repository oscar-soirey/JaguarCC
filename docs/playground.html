Pyodide is loading the real jcc.py compiler locally in your browser. Give it a few seconds, then hit Run: it will transpile your Jaguar code to C, compile that C with a real clang toolchain running as WebAssembly, and execute the resulting binary. The first run downloads the C toolchain (~90MB) — that only happens once.
